# 🎬 Cinemora AI

**Cinemora AI** is a next-generation AI-powered video generation platform that helps users create cinematic videos from simple text prompts.

## ✨ Features

- 🎥 AI Video Generation
- ✍️ Text-to-Video Prompts
- 🔐 Firebase Authentication
- ☁️ Cloud Storage
- 📜 Video History
- 📱 Mobile-Friendly Design
- 🌙 Modern Dark Theme
- 🚀 Fast and Simple Interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Firebase
- GitHub
